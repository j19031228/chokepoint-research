# chokepoint-research · 产业链卡点研究

把「供应链卡点(choke point)投研法」落地成一套可复用的 Agent 方法 + 一份用真实公开数据跑出来的 A 股 AI 基础设施产业链实证报告。

> 灵感来自公开传播的 Serenity(@aleabitoreddit,俗称「白毛股神」)式瓶颈投资思路,以及 GitHub 上若干蒸馏它的开源 skill 项目。
> 本项目**不复刻**任何仓库的文本:规则、模板、数据源、脚本全部重写,并按本机条件(A 股 / 中文 / 无付费数据源)做了适配。

## 它跟普通「荐股 prompt」的区别

| | 普通做法 | 本项目 |
|---|---|---|
| 输出 | 「买什么」+ 综合评分 | 「哪些线索值得再花时间」+ 什么事实会推翻它 |
| 信息 | 混在一起 | **分层标注**:事实 / 观点 / 推断 / 风险 / 未查到 |
| 数字 | 看起来精确 | 每个数字带来源 + 日期;查不到就写 `[未查到]` |
| 结论 | 单边看多 | 强制 ≥3 条**可判定**的反证条件 |
| 依据 | 研报、社媒 | 证据阶梯:公告年报(唯一能下结论的一档)> 机构 > 媒体 > 研报 > 社媒(仅线索) |

## 四步流程

1. **拆链**:终端需求 → 系统集成 → 关键器件/芯片 → 上游材料/设备 → 基础设施;每层记「玩家数量级 / 扩产周期 / 认证周期」
2. **六筛定位卡点**:供应商数量、扩产周期、客户认证周期、断供后果、替代路线、定价权 —— 四项以上为强
3. **落到标的**:链上位置 + 主营占比(必须有出处)+ 一手证据 + 最新报告期财务,并检查排除项
4. **出报告**:链条图 / 六筛表 / 标的表 / 分层证据 / 反证条件 / 未查到清单

## 用法

```bash
# 行情快照(免 key)
python3 scripts/quote.py 300308 300502 688498
# 板块成分
python3 scripts/quote.py --bk BK0922 --top 20
# 重新渲染信息图
python3 scripts/render_map.py
```

作为 Agent skill 使用时,把 `SKILL.md` + `references/` 装进你的 skill 目录即可(本机安装在 `hermes/skills/research/industry-chokepoint/`)。

## 实证报告的一句话结论

A 股在 AI 基础设施链上是**倒置**的:中游(光模块集成)已全球第一,但上游每一层都被美日垄断 —— T-glass 玻纤布(日东纺 >90%)、ABF 树脂膜(味之素 >95%)、载体铜箔(三井 ~90%)、InP 衬底(三家 >90%)、高端 EML(美日三家 65–70%)。
**越往上毛利率越高**(模块 46~48% → 光芯片数据中心业务 84%),这个梯度本身就是卡点存在的证据。

## 边界

- 只做**研究辅助**,不执行交易、不给买卖点、不预测大盘。
- 所有内容为公开信息整理,可能随时过期;**不构成投资建议**。
- `[未查到]` 就是没查到,不用估算值填充 —— 这是本项目的硬规则。
