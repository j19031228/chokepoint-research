「白毛股神」方法讲解 · + A股卡点面板

供应链瓶颈(choke point)投资法 · 归纳自公开方法论与 10 个开源蒸馏项目(实读)
研究辅助,不构成投资建议

一、他到底在找什么一句话 + 一个隐喻

在 AI 这类超大规模基建周期里,决定利润分配的不是「谁最热」,而是「谁在最难绕开的那个环节上」。
他不买最亮的公司,买没有它整条链就停摆的环节。
「霍尔木兹海峡是全球石油的咽喉。一旦封锁,所有人受影响。
但如果你在霍尔木兹海峡拥有股份,你就拥有了定价权。」

翻译成投资语言:找的不是最大的石油公司,而是那条谁都绕不过去的窄口。窄口的特征:

  • 替代品极少
  • 建新产能要很久(2–4 年)
  • 客户换供应商成本极高

它的好处不是「增长快」——增长快的公司很多;好处是能涨价。

推理链:钱从哪来,卡在哪

终端需求爆发(AI 算力采购) ↓ 钱往下流 系统集成(服务器/机柜) 玩家多、利润薄 —— 不是卡点 ↓ 关键器件(光模块/PCB/电源) 中国已很强,但受制于上游 ↓ 上游器件与芯片(激光器/衬底/快接头) 玩家 3–8 家 ↓ ★ 上游材料/设备(玻纤布/ABF膜/载体铜箔/InP) 玩家 1–3 家

关键动作是「多跳上溯」:不要停在第一层瓶颈(比如光模块),继续追问「光模块被什么卡住」。他常一路追到衬底、材料,甚至织布机这种装备环节。

为什么这条链是「倒置」的

位置中国的份额毛利率水平
光模块集成(中游)全球第一(中际旭创 2025 年销售额居首)46.6% ~ 48.5%
光芯片(上游)25G 以上国产化率约 4%84%(源杰数据中心业务)
玻纤布 / ABF 膜(更上游)依赖进口,日东纺 / 味之素垄断掌控者拿走定价权
下游份额高、上游份额低,而毛利率正好反过来 —— 这就是卡点在财务上的指纹。

他要的两类机会

类型特征例子
技术跃迁型新技术替代旧技术,旧技术突然被禁CPO 替代可插拔光模块
供给受限型关键材料被少数公司锁死,扩产 2–4 年InP 衬底、T-glass 玻纤布、高纯石英

他特别偏爱第二类里的小市值公司(理由:弹性大)。这也是风险最大的地方。

二、完整知识体系四步 + 六筛 + 两纪律

第 1 步 · 拆链(自上而下五层)

层级内容每层要记三件事
终端需求云厂商 / 算力采购方玩家数量
扩产周期
认证周期
这三个数字直接决定第 2 步能不能过
系统集成服务器整机 / 机柜 / 数据中心
关键器件/芯片GPU / ASIC / 光模块 / PCB / 电源
上游材料/设备衬底 / 玻纤布 / 铜箔 / 设备
基础设施供电 / 制冷 / 场地

第 2 步 · 六把筛子(全过才算卡点)

#筛子强信号弱信号
1供应商数量全球可供 ≤3 家≥10 家、格局分散
2扩产周期>18 个月<6 个月可放量
3客户认证周期>6 个月、一供难换即插即用
4断供后果直接停产/停线可库存缓冲
5替代路线无成熟替代有可绕开方案
6定价权毛利率连续多期上行涨价不落到利润
判读:四项以上为强 → 卡点候选;两项以下 → 只是热闹。

第 3 步 · 落到标的(四维核验 + 排除项)

  • 位置:链上具体环节 + 该业务占主营比重(必须有出处)
  • 证据:公告 / 年报 / 互动易 / 招投标 / 专利能验证到的客户或产能
  • 财务:最新报告期营收、毛利率、经营现金流(注明报告期)
  • 资金估值:机构覆盖、估值分位 —— 标为观点,不作结论

命中就该剔除的排除项:有业务但不是主营(蹭热点) / 竞争格局分散 / 产能半年就能扩出来 / 「国产替代」逻辑不成立(全球都没货) / 已被充分定价 / 无机构关注且成交额过低。

第 4 步 · 出报告(必须含六块)

链条图 · 六筛表 · 候选标的四维表 · 分层证据清单 · 反证条件 · 未查到清单

贯穿全程的两条纪律

纪律 A · 分层标注(防幻觉):每条信息标 [事实] / [观点] / [推断] / [风险] / [未知]。查不到就写 [未查到],不许用估算数字冒充查证结果。

纪律 B · 证据阶梯(防被带节奏):

级别来源能否单独下结论
E0公司公告、年报、交易所文件、招投标、专利、官方规则✅ 唯一能下结论的一档
E1行业协会、官方统计、第三方调研⚠️ 需注明机构与口径
E2权威媒体⚠️ 需交叉验证
E3券商研报❌ 只作观点
E4社媒、自媒体、股吧❌ 只作线索,必须回到 E0 验证

定性与数字分轨:链上位置这类定性判断可以用标注过的推断;但份额、市场空间、目标价这类数字结论必须有一手源,否则留空。

商业阶段六段:研发 → 送样 → 客户认证 → 量产 → 有订单 → 已确认收入。送样 ≠ 订单 ≠ 收入 —— 这是这类研究最高频的翻车点。

三、反证与熔断这套方法最值钱的部分

大多数「荐股 prompt」只会告诉你为什么该涨。这套方法的核心纪律是:先说清楚什么情况下它不成立。

一个只能看多的框架,在任何时候都会得出「可以买」——那它等于没有信息量。

反证条件的三条写法要求

  1. 可判定 —— 能通过某份公告 / 某期财报 / 某个官方数据来证伪
  2. 带时间窗口 —— 「2027 年上半年之前」而不是「未来某天」
  3. 说明降级后果 —— 出现了,结论从 A 降为 B(而不是「要注意风险」)
❌ 反例:「若市场情绪转弱」「若行业竞争加剧」
✅ 正例:「若 2027H1 公司新厂未按期量产且继续不涨价 → 降级为『有壁垒但无定价权』」

熔断表(比风险清单更可执行)

结论时间窗口必须发生的 binary 事件未发生 → 降级验证方式
某材料卡点延续到 20282027H1新厂按期量产且不降价降为「有壁垒无定价权」公告 / 法说会
某公司卡点含量高下一期财报该业务收入环比回升说明卡点地位不牢定期报告

填不满这四列,说明这条结论不可证伪,应降级为「叙事」。

反直觉点:市场会「惩罚」维持卡点的人

实例 · 日东纺(2026-05-13):当天股价盘中跌超 12%。
原因不是需求崩了 —— 而是公司宣布:当期净利指引同比 -59%(低于预期)+ 不增产 T-glass(维持稀缺性)。
但同期它的电子材料事业营业利润是 +39.6%。

读法:当卡点持有者选择「不扩产」时,短期财务一定难看,股价也会先跌;但这恰恰是它在维持议价权的证据。要判断的是它在谈判桌上的位置,不是当期 EPS。

这个信号的镜像就是:业绩超预期但股价跌、资金撤退,常常是「买预期卖事实」的阶段切换,而不是基本面变坏。

四、六个翻车点与边界

翻车点怎么避免
把「送样」当「订单」商业阶段六段必须标清楚
把研报当事实券商观点是 E3,只能当观点
把社媒爆料当证据E4 只是线索来源
默认「国产替代」成立先问:国外是否也缺货?有无更优替代路线?
只搜多头论据反证那一栏必须搜 —— 最典型的失败模式
无源数字每个数字跟来源 + 日期,否则留空

关于本人,先厘清三件事

  • 收益率是自述的,未经审计 —— 流传的「3800%」来自他本人公开材料,当营销文案看
  • 持仓披露 ≠ 当前持仓 —— 公开说「看好」的时间和现在可能隔很久
  • 有幸存者偏差 —— 传播的是活下来的赢家,被同一逻辑带进坑的不会传播

这套方法不适用的情况

纯题材炒作、无实质产业逻辑的小票 ｜ 预测大盘走势 ｜ 需要精确估值(早期/亏损公司) ｜ 想找短期买卖点。

它真正给你的东西

把「我觉得这个环节很关键」这种模糊感觉,变成一张有来源、有分层、有反证条件、可以拿去被人挑战的纸。

三个反常识信号可核实的

② 中际旭创:利润与现金流背离

2026H1 归母净利 +241.70%(136.51 亿),经营现金流 -44.08%(18.00 亿);总负债 +82%,研发 +96.9%。
利润 +241% / 现金流 -44% 的剪刀差,需下个报告期验证。

③ 天孚通信:卡点的直接证据

有源光器件收入 -19.57%,财报明确归因「个别物料阶段性供给短缺」,而非需求不足;存货 +103%(战略备货)。
需求爆发的环节却无法提产 —— 这就是卡点。
