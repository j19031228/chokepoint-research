# 中国市场免费一手数据源与检索套路

## 一、一手源(E0)

| 要找什么 | 去哪 | 怎么用 |
|---|---|---|
| 公告 / 年报全文 | 巨潮资讯网 cninfo.com.cn | 关键词检索 + 下载 PDF;年报看「主营业务分析」「主要客户」「产能与在建工程」 |
| 问询函、监管函 | 上交所/深交所官网 → 信息披露 → 监管问询 | 交易所追问的问题 = 市场最该关心的疑点 |
| 公司对投资者的答复 | 深市「互动易」irm.cninfo.com.cn、沪市「上证 e 互动」sns.sseinfo.com | 一手口径,但属于公司自述,只算「公司称」 |
| 招投标 / 中标 | 中国招标投标公共服务平台、运营商采购平台(中国移动采购与招标网、中国电信/联通阳光采购) | 能验证「是否真进了供应链」 |
| 专利 | 国家知识产权局检索系统、Google Patents | 验证技术布局真伪与时间点 |
| 海关进出口量价 | 海关总署「统计数据在线查询平台」 | 验证某材料是否真在进口/出口放量 |
| 股权与工商 | 国家企业信用信息公示系统 | 关联方、合资公司 |
| ETF 持仓 | 基金公司官网、天天基金 | 看主题基金是否真配到了瓶颈环节 |

## 二、二手源(E1/E3)

- 行业协会:CPCA(印制电路)、中国光学光电子行业协会(COEMA)、SEMI、中国光伏行业协会
- 第三方调研:TrendForce、Omdia、Yole、LightCounting —— 多数报告付费,免费只拿到摘要数字,**引用要写清是摘要**
- 券商研报:看观点与假设,不当事实用

## 三、行情与资金(免登录)

- `scripts/quote.py` 走东方财富公开接口:个股快照 + 概念板块成分。
- 注意:北向资金实时/每日明细的披露口径几经调整(近年已大幅收紧),引用前务必核实当期规则,不要沿用旧口径的「今日北向净买入」。

## 四、检索套路(搜什么词)

| 目的 | 查询式 |
|---|---|
| 环节格局 | `<环节> 全球格局 / 供应商 / 集中度 / 国产化率` |
| 产能与扩产 | `<公司> 扩产 公告 / 在建工程 / 产能 爬坡` |
| 客户验证 | `<公司> 客户 认证 / 送样 / 批量供货 / 定点` |
| 财务质量 | `<公司> 年报 毛利率 主营构成 前五大客户` |
| 需求端 | `<云厂商> capex 指引 / 资本开支 财报` |
| 政策 | `<环节> 出口管制 / 补贴 / 规划 原文` |
| 反证 | `<环节> 产能过剩 / 价格下跌 / 替代技术 量产` |

**反证那一栏必须搜**:只搜多头论据会得到必然看多的报告,这是这类研究最典型的失败模式。

## 五、本机检索注意事项

- `web_extract` 后端为 ddgs,只能搜索、不能抓正文 → 抓页面用 `curl` 或 `browser_exec`。
- 中文财经页面多为 JS 渲染,`curl` 拿不到正文时直接用 `browser_exec`。
- 抓到的数字一律记录 URL + 日期,当场写进证据清单,不要靠记忆回填。
