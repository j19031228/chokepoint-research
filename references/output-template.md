# 报告模板

> 复制这份骨架使用。方括号内为填写要求。**空着的栏目保留「未查到」,不要删、不要编。**

```markdown
# [产业链名] 卡点研究

- 研究日期:[YYYY-MM-DD]
- 研究范围:[链的起点与终点,例如「AI 服务器算力基础设施,从供电到光互连」]
- 数据截止:[最新报告期 / 最近事件日期]
- 立场声明:研究辅助,非投资建议;以下每分钟都可能过期。

## 0. 结论速览(≤5 行)

1. 最像真卡点的环节:[X],因为 [一句话依据]。
2. 最像叙事而非卡点的环节:[Y],因为 [一句话原因]。
3. 最该下一步核实的三件事:[a / b / c]。

## 1. 链条图

[文字缩进链条图,标注每层玩家数量级、扩产周期、认证周期]
```

## 写作纪律

- 每个数字后面必须跟**来源 + 日期**;没有就写 `[未查到]`。
- 「事实」段落只放 E0/E1;券商观点、社媒说法一律放「观点」。
- 反证条件要写得**可判定**(能通过某份公告/某期财报证伪),不要写「若市场情绪转弱」这类无法判定的句子。
- 不给综合评分;排序即结论。
